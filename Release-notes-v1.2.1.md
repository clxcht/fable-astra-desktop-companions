# Fable + Astra v1.2.1

All 34 display sprites are now clear of the gray watermark text. The transparent edges, expressions, conversation props and taskbar alignment are preserved.

## Install on this Windows ARM64 computer

1. Download **Fable-Astra-Setup-v1.2.1-win-arm64.exe** from the assets below.
2. Open it and click **Install and launch**. Leave automatic startup checked if wanted.
3. Find their controls in the **Fable + Astra system tray icon**.

The installer includes the .NET 8 runtime, installs for your Windows account, creates the Start menu shortcut and preserves existing preferences. It appears in Windows Installed Apps for uninstalling. This build is for ARM64 Windows. The installer is not code-signed.

The app includes 21 offline conversations, 126 explicit sprite cues and 17 pose pairs. The companions remain above ordinary windows with their cropped legs meeting the taskbar edge.

**Fable-Astra-Backup-v1.2.1-2026-09-15.zip** is the saved setup backup with editable source and preferences. Extract it and run `Restore.cmd` to restore that saved setup; this portable backup uses the .NET 8 Desktop Runtime. Previous backup ZIPs remain in the repository.

The repository and this release are private. `SHA256SUMS.txt` contains checksums for the installer and saved setup ZIP.
